# Kannada review sheet

Every word the app shows, English on the left, Kannada on the right.

**How to use this.** Read down the Kannada column. Where the wording is wrong, awkward,
or too formal for a shop counter, write the better version next to it. You do not need to
look at any code — the `Key` column is only there so a correction can be applied to the
right string.

Two things to watch for:

- `{n}`, `{amount}`, `{name}`, `{days}`, `{no}`, `{date}`, `{mm}`, `{dots}`, `{reason}`,
  `{what}` are filled in by the app. Keep them exactly as they are, but move them if
  Kannada word order needs it.
- `␣` marks a space at the start or end of a string that has to stay there.

Generated by `npm run i18n:review` — do not edit this file by hand, edit the `KN` block in
`shared/src/i18n.ts` and regenerate.
